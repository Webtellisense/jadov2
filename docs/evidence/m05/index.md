# M0.5 visual review

32 screen states × four widths = 128 actual browser screenshots. Each file is captured after overflow and axe checks.

The `/dev` and `/design` images are a restricted local prototype using fictional PostgreSQL data. Public production never exposes these records. Account/admin/owner views are development-session shells, not evidence of live business operations.
